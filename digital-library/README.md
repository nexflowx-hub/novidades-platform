# DIGITAL LIBRARY — Novidades.store

Acervo editorial integral do projeto Novidades.

## Regra principal

Este diretório preserva **todos os títulos inventariados**, inclusive materiais marcados como `ATUALIZAR`, `REVISÃO ESPECIALIZADA`, `EXCLUIR` ou `QUARANTINE`.

**Estar no repositório não significa estar aprovado para venda.**

A publicação comercial continua condicionada ao gate editorial: licença, atualização factual/técnica, segurança, português, capa, entrega e checkout.

## Fonte canónica

- Google Drive original: 10 Mil PLRs / Bônus 1 / Bônus 2.
- Catálogo mestre auditado: 437 candidatos.
- O Drive original permanece como fonte imutável.
- Este repositório passa a ser a camada de inventário, classificação, transformação e produto.

## Estrutura

- `catalog/` — catálogo mestre, resumo, packs e regras de QA.
- `audit/` — auditoria editorial e critérios.
- `library/` — índices por categoria.
- `source-manifests/` — fontes do Drive, incluindo arquivos grandes demais para GitHub.
- `quarantine/` — materiais bloqueados comercialmente, mas preservados.
- `products/` — versões comerciais reconstruídas/aprovadas.

## Status

- `PUBLICAR APÓS QA` — candidato comercial após gate mínimo.
- `ATUALIZAR` — precisa reescrita/atualização antes de venda.
- `REVISÃO ESPECIALIZADA` — depende de revisão técnica/profissional.
- `EXCLUIR / QUARANTINE` — permanece arquivado, com checkout bloqueado.

## Limite físico do GitHub

Alguns pacotes-fonte no Drive ultrapassam 100 MB e vários chegam a centenas de MB ou mais de 1 GB. GitHub normal não aceita arquivos individuais acima de 100 MB. Esses pacotes serão preservados no repo por manifesto/origem Drive; os e-books individuais extraídos e arquivos menores podem ser materializados no repositório.
